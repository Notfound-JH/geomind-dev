# Agent选择组装场景与任务GT结合

2026-11-09。按用户要求，应用[geomind-research](../../../.agents/skills/geomind-research/SKILL.md)，把已实现的场景组装与原任务GT求解连接起来；规划agent显式选择场景、布局、资产和任务，记录选择依据，不增加另一套GT注册、模拟环境或外部模型调用。

## 已实现入口与状态

现有 `geomind.tools.research_pipeline` 新增 `--assembly-options`、`--assembled-request`、`--audit-assembled`。原 `--request/--audit` 行为和操作模式拒绝边界保留。请求阶段为assemble_and_solve_gt，自然操作意图不改成坐标题冒充机器人执行；具体协议见[使用文档](../../assembled_tasks_zh.md)。

可选项实际查询为102个场景、5种布局、28种可信尺度描述资产，以及4个原生静态GT：SelectByOrder、InferMidpoint、ProjectOntoLine、ReflectAcrossLine。资产可解析不代表已逐项物理认证，动态/历史任务及其他legacy求解器未在本入口接通。

## 公开输入与反捷径边界

初版工程验证发现沿X直线的内部资产编号按位置递增。最终绑定用实测状态hash派生独立语义ID置换和公开列表顺序，Order候选文字按语义ID枚举；请求仍用内部资产ID，物理绑定映射只放evaluator。同一场景跨任务保持完全相同映射与公开顺序。最终Order答案是obj_004而非序号2对应的obj_002。

公开观察含自然抓放指令、米制单位、world轴约定、实测对象位置及图像引用；无GT、角色参数、prim路径、来源hash或内部身份映射。这是结构化状态加图像的条件，图像无额外编号贴纸；不能称为纯视觉或模型性能测试。此处消除了明显编号/列表顺序编码，没有声称已验证全部捷径。
