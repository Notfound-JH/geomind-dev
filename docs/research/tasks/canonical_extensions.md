# 十项 Canonical 任务的有界实现卡

2026-11-10。对应用户“按现有任务质量和指令难度完善占位任务，交付 27 任务展示网页”的请求。本文记录本轮采用的明确 Base 变体、输入和验收边界；不是对任意图、任意区域、任意多跳或模型表现的广义能力声明。

总目录仍为 [27 种任务](../../canonical_task_families_zh.md)。原 20 个已验收实例覆盖 17 种类型：顺序选择的 First/Last/Second 合为一种，拓扑放置的 Inside/OnTop 合为一种。本轮新增的十种类型补足目录，不把十个新实例误称为仅七项缺口。

状态：十项有界合同、生成配方及求解/独立检查已实现；本轮十例真实正负操纵、独立原始状态/有效错误命令、来源与外部/腕部媒体全部通过。最终展示27/27类、30/30实例（旧20历史+新10），13个显式重试版本保留。来源和失败修复见[本轮实验记录](../experiments/2026-11-10-canonical27-completion.md)，不把CPU测试、历史成绩或诊断到达计为新动作通过。

## 静态选择：五种明确结构或关系

源码：[extended_static_tasks.py](../../../geomind/episodes/extended_static_tasks.py)。生成的角色名称仅属于评估端，绑定为中性公开别名后才提供 observation。使用真实方块和可见的桌面箭头、连线或区域框，不把几何最近邻当作结构邻接。红、蓝等参考标记明确采用运动学固定 context，待抓取棕色候选为真实动态刚体；固定标记不作为动态操纵能力证据。随机化只允许明确的整体 XY 平移，禁止破坏结构与条件必要性的逐对象抖动。

| 类型与本轮变体 | 自然指令 | Base 难度和求解约定 |
| --- | --- | --- |
| `SelectByBranchPosition`：`RootedDirectedTreeMarkedBranchOrdinal` | 从红色起点沿箭头走，在分叉处走蓝色标记所在的分支，拿起蓝色标记之后的第二个棕色方块。 | 七节点有根有向树；根、分支标记、走向及序位均可见。需要沿正确分支继续计数，其他分支保留候选。不是未定义的通用图遍历。 |
| `SelectByRegion`：`VisibleRectangleInterior` | 拿起桌面长方形框内的棕色方块；蓝色和黄色标记是这个框的两个对角。 | 明确世界 XY 轴对齐长方形，四个棕色候选，内部唯一对象；候选距边界至少 25 mm，近边界实例拒绝，不擅自增加最近对象规则。 |
| `SelectByPathDistance`：`VisibleUnitEdgeShortestPathFarthest` | 沿桌面连线，每段算一步，拿起从红色起点走过去所需步数最多的棕色方块。 | 可见无向连通图，每边权重恰为 1，比较最短路径步数；并列与不可达拒绝。设计要求路径最远者与欧氏距离最远者不同。未实现任意权重或不可达目标的扩展。 |
| `SelectByTwoRelations`：`IndependentRightAndFrontIntersection` | 以橙色箭头所指为前方，拿起既在红色标记右边、又在蓝色标记前方的棕色方块。 | 四个候选，世界 +X 为右、可见箭头指向 +Y 为前；两关系交集唯一。单独每条关系至少有两个候选，并分别有只满足其中一条的干扰项；方向边界裕量 35 mm。 |
| `SelectByIndirectReference`：`TwoHopNearestReferenceThenCandidate` | 先找离红色标记最近的蓝色标记，再拿起离那个蓝色标记最近的棕色方块。 | 两个蓝色中间参照、三个棕色候选；先确定中间对象再进行第二次距离选择。每跳最近/次近距离差大于 15 mm。直接从红标记选候选和选择另一个蓝标记必须改变答案。 |

间接指代的三个棕色候选统一为40×40×50mm，质量仍0.05kg；其余静态候选保持40mm方块。统一高度消除夹持偏心，不以高度标出正确对象，XY两跳关系/捷径及原指令均保持。

这些例子保留与现有任务相当的自然操作形式：选择结果必须被实际抓起并持稳，不能用报告对象编号或末端到达替代。物体数量、视觉组织、关系链和干扰条件按本表显式记录；没有模型比较，不能把合同复杂度相近写成模型难度已统计等效。

## 几何放置：保留公共三维定义，明确桌面变体

源码：[extended_geometry_tasks.py](../../../geomind/episodes/extended_geometry_tasks.py)。本轮均为 `TabletopPlane` 变体：红、蓝参考方块和绿色移动方块位于实际桌面，使用实测世界 AABB 中心计算 XY，目标 Z 来自实测桌面及移动物体尺寸。此限定保证答案是合法支撑点，不将任意三维计算点放在空中。

| 类型 | 自然指令 | 唯一性与独立检查 |
| --- | --- | --- |
| `ProjectOntoLine` | 把绿色方块移到红、蓝方块连成的直线上，尽量少移动。 | 使用无限直线，不夹紧为线段；“尽量少移动”确定唯一正交投影。独立检查目标在线上、移动向量与直线垂直。不是中点放置。 |
| `ReflectAcrossLine` | 以红、蓝方块连成的直线为对称轴，把绿色方块移到桌面上与它对称的位置。 | 在明确的水平桌面中作轴对称。独立检查源点/目标中点在线上、位移垂直于轴、两侧有符号距离相反。 |

两例均使用斜向参考轴和斜向偏移，要求参考线长至少 100 mm、原点离轴至少 60 mm、目标离参考对象至少 80 mm，并仍需真实桌面余量、参考保持和机器人可达性验收。

另有明确的源条件质量约束：实测投影必须离红蓝端点中点至少 **30 mm**，以排除忽略绿色源点的中点捷径。当前配方线参数为 `.65`，手算投影为 `(.424,.036)`；投影和中点相差 43.267 mm，反射和以中点作点对称相差 86.533 mm。生产从实测位置检查该约束，独立检查器用源点相对中点的沿轴标量偏移另算。固定参考物、只改变源点，使线参数 `.65→.35` 的两个合法样例给出不同答案。首轮 `.5` 附近的两个物理动作虽通过，因质量不足已排除最终计数。最终`.65`版本已完成真实正负放置和独立几何/原始状态审计；源条件必要性的反事实是CPU检查，不冒称视觉模型实验。

原生 release-2 的 `InfiniteLine3D` 投影及三维绕轴反射合同保持原含义；本轮桌面例不能支持一般三维能力归因，也不替代 [ProjectOntoLine 旧研究卡](ProjectOntoLine.md)中的非零 Z 捷径诊断与未决研究问题。指令和操作变体均显式命名，未静默重写旧成绩。

## 时序任务：三个不同机制

源码：[extended_temporal_tasks.py](../../../geomind/episodes/extended_temporal_tasks.py)。每例五个真实刚体；事件由已有 `MoveObject` PD 外力机制执行 41 个连续指令路点、持续 4 秒。指令路点与计划终点仅为事件命令，所有 GT 和验收读取实测历史及当前状态。事件外力须在抓放前撤除并重新落稳，不能把外力搬运当作机器人抓放。

| 类型与本轮变体 | 自然指令 | 机制和输入必要性 |
| --- | --- | --- |
| `DetectSceneChange`：`UniqueDisplacementOverThreeCentimetres` | 记住桌上方块的位置，等画面恢复后，把刚才被移动的那个方块拿起来。 | `Observe.End` 与查询状态比较，唯一候选位移超过 30 mm，阈值周围至少留 6 mm 判定裕量，其他候选漂移不超过 12 mm。本轮仅沿用已确认的位移语义，不实现或决定新增/移除语义。 |
| `UpdateEmptySlot`：`CurrentVacancyAfterOneOccupancyTransfer` | 看清四个格子的占用情况。方块移动结束后，把棕色方块放到现在空着的那个格子里。 | 四个可见格子、三个占位块、一个待放棕色块；一个占位块进入原空格，使空格改变。槽位由实测参考标记的相对位置确定，按当前占位计算唯一空格；每个占位块距所属格中心不超过 25 mm。**当前状态足以决定答案**，历史只核验占位事件确实改变空格，不把此例宣传为历史记忆必需任务。 |
| `TrackObjectOrigin`：`InitiallyUniqueBlueRegionSourceThroughVisibleCycle` | 看着这些灰色方块移动，结束后，把最初在蓝色方框里的那个灰色方块拿起来。 | 四个同外观灰块及一个蓝色参考标记，连续可见的非相交循环混合。初始蓝框内唯一灰块，来源边界留 8 mm 裕量；源灰块实际离开至少 80 mm，终态候选间距至少 65 mm，当前蓝框内须是另一候选。最终当前区域查询必须给错对象，不能替代初始来源。 |

槽位和来源框为无碰撞 `BasisCurves` 可见线条，不添加台面、悬空托板或物理支撑。背景、真实桌面和对象尺度由实际组装 USD 提供。

`TrackObjectOrigin` 的公开结构化 observation 当前仍含稳定中性 ID、可读对象属性及精确状态。模型可以利用稳定 ID 维持身份；本轮只验证合同与动作链，不声称纯图像身份追踪或学习模型表现。蓝框在画面中仍可见，但没有一直贴在目标上的“来源标签”。

来源判定使用实测 `Observe.End` 位置。CPU 检查构造相同终态、改变初始身份来源的两例，要求正确身份跟随历史改变；该检查不是 PhysX 重执行，也不是对受评模型的记忆测试。其他事件初末状态与轨迹是否真实可辨识，须在实际录像和原始状态审计中检查。

DetectSceneChange 的定义边界沿用[原研究卡](DetectSceneChange.md)和[语义决策记录](../decisions/detect_scene_change_semantics.md)，本轮不关闭增删语义问题。

## 共同的独立验证与反捷径要求

生产求解器 `solve_spec` 与独立检查器 `check_spec` 分开。检查器不调用生产求解器来生成预期答案，但共用合同 schema、输入验证和物体绑定；独立性范围应如此报告。

| 机制 | 必须保留的反例或消融 |
| --- | --- |
| 分支序位 | 错分支、错序位；断开、重复父节点或环图应拒绝。 |
| 区域 | 外部候选和边界附近无效实例；平移后区域与答案关系保持。 |
| 路径距离 | 欧氏最远与路径最远不同；图断开、并列最远或权重不符应拒绝。 |
| 双关系 | 分别删除右方/前方条件，每个单条件都留下干扰候选。 |
| 间接参照 | 删除第一跳、直接从红标记选择、换另一个蓝标记均改变答案。 |
| 投影/反射 | 错误连续落点拒绝；独立几何恒等式核对，退化线和无合法支撑拒绝。 |
| 位移检测 | 不移动、两块移动、阈值附近变化均拒绝；不能只读取计划中指定的移动角色。 |
| 空格更新 | 未执行转移、块停在格间、重复占位及放到已占格均拒绝。 |
| 来源追踪 | 当前蓝框占位者作为错误答案；相同终态换历史会换答案；源对象未真正离开或初始框内多对象应拒绝。 |

选择类错目标对照必须真实执行错误对象抓起；放置类错落点对照必须完成错误命令、松爪、退离并在合法支撑处放稳，再被冻结正确 GT 拒绝。动作失败不能冒充有效负控。

## 共同的物理完成门槛

沿用 [assembled_actions.py](../../../geomind/episodes/assembled_actions.py) 的实测判据和现有 Robotiq 执行器，不放宽阈值换取通过：

- 抓起：正确物体抬升 **超过 60 mm**，线速度不超过 **0.01 m/s**、角速度不超过 **0.1 rad/s**；夹爪闭合、物体中心距 TCP 不超过 **80 mm**；其他参考物体位移不超过 **5 mm**、姿态误差不超过 **0.12 rad**。
- 桌面 Point 放置：实际抓取、运输、释放和退离；实测中心误差不超过请求的物理位置容差（默认 **10 mm**），底面与实际支撑高度误差不超过 **6 mm**，保守足迹在实测桌面内；速度与参考保持要求同上。
- 连续有效时长：不少于 `max(60 ticks, request.dwell_steps, ceil(0.5 / dt))`。Robotiq 240 Hz 下至少 120 ticks；若实例请求更长则按请求，不降低到默认值。
- 读取原始物体、关节与控制状态，检查限位、预算、实际时钟；动作阶段只发送关节/夹爪目标，不进行物体位姿写入、吸附、焊接或外力搬运。
- 初始组装另外运行 600 个物理步，并要求至少连续 60 步通过支撑、位姿和速度检查；初始落稳不计为任务动作完成。

每个物理 worker 上限 420 秒、GPU 串行、先单例再批量。每次重试新目录，保留原失败，只有明确修复后重试，不换 seed 补成功。结论绑定逐例实际配置、源码快照和原始证据；没有实际执行且通过的实例不计入完成数量。

## 最终执行配置与复现

新十例均使用scene65、seed0、Panda＋Robotiq、240Hz和最多12000动作步/420秒worker。默认基座XY为[-.12,.32]；Path和Reflect为[-.04,.32]，Detect为[-.06,.44]，Z均取实测桌高。正负均在独立worker执行。最终Robotiq前侧腕相机v2仅在最后Reflect/Indirect新运行中实际记录，其他实例保留各自保存相机版本，不能追认为新安装重渲染。
