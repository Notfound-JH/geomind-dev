# GeoMind 本地展示页

启动：

```bash
python -m geomind.tools.dashboard --port 8765
```

打开 http://127.0.0.1:8765 。服务仅绑定本机，不依赖 Isaac Sim、GPU、前端构建工具或外部 CDN。

- 总览：当前任务数、原生实例数、最新可播放结果、占用空间。
- 测试与视频：分批次查看实际执行结果，切换实例、完整过程与 agent 遮罩视角。
- 任务与场景：检索注册任务，查看原生实例、场景引用和实际验证记录；注册不等同于实现。
- 更新记录：从首次启动建立基线，后续记录配置/代码变化、新报告和清理动作。
- 数据清理：展示完整文件清单、大小和目录，输入目录名确认永久删除。

页面每 15 秒重新读取配置和 `outputs/`。测试输出使用独立目录，并写入 `report.json`；
中途结束但保留 `cases/` 和 `traces/` 的批次也会显示，且不会被标为已验证。
配置解析失败会显示提示，修复后再次刷新即可。正在播放时不自动替换视频，手动刷新可载入新结果。

清理会删除选中测试目录内所有产物，以及同名 ZIP、SHA256 文件，包含视频、轨迹、证据和配置副本。
正式配置 `geomind/configs/`、项目源码不删除。预览令牌 5 分钟有效，文件清单/大小/修改时间变化会取消删除。
符号链接和 outputs 之外的路径不能通过清理接口删除。不要清理正在写入的测试目录。

精简验证摘要和更新记录保存在 `data/dashboard/history.json`，即使产物被清理，仍能看到过去的验证结果；
摘要只保留结果、指令和误差等信息，没有视频或逐帧轨迹。服务重启后这些摘要仍在。
原始产物清理后无法恢复，确认前请完成检查或另行备份。

## 任务发布版本

原有 `tasks/` 与 `vla_tasks/` 中的 59 个注册入口标注 `release_version: "1.0"`。
后续生成的 `episodes/` 原生测试实例标注 `release_version: "2.0"`，生成器和原生 scaffold
也会写入该字段。版本是字符串，与 schema_version、旧整数 version 及 ID 的 `_v0` 后缀无关。
同一任务名称可以有原来的 1.0 占位注册，以及后续可执行的 2.0 实例。

网页任务卡片和视频详情显示发布版本。此前的 isaaclab_physx 报告按本次确定的分类在展示层
标为 2.0；不会改写历史报告、视频或冻结配置，因此旧证据的哈希保持不变。
新运行会在 case 报告中明确记录 release_version。修改后的当前配置和代码哈希与历史快照不同，
回放旧证据请使用其数据包中的冻结版本。
