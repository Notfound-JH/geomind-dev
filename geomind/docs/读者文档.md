# 读者文档（当前真实能力）

## 你现在可以做什么

- 用 `task_id` 或 alias 启动单任务。
- 切换基础 policy（`random` / `zero`）。
- 批量跑任务并输出逐任务结果与汇总。

## 目前不是完整能力

- 当前正式运行入口已经分成“注册入口 + runtime delegate”两层：
  - `temporary_mock_delegate`（默认，走 `mock` backend）
  - `isaaclab_native_delegate`（minimal runnable stub，非真实物理）
- 文档中的“可运行”指主链路可运行（解析、配置、注册、运行、结果输出）。

## 运行一个任务

```bash
python -m geomind.runners.run_task \
  --task-id ReindexExtreme_v0 \
  --policy random \
  --max-steps 80
```

也支持 alias（例如 `reindex_extreme`），会自动解析到 canonical task_id。

走 native delegate stub（仅验证选通，不代表真实 IsaacLab 物理）：

```bash
python -m geomind.runners.run_task \
  --task-id PlaceDirectional_v0 \
  --backend isaaclab \
  --policy zero \
  --max-steps 5
```

## 批量运行

按组（或同名 preset）：

```bash
python -m geomind.runners.run_suite --group base --max-steps 100
python -m geomind.runners.run_suite --group aug --max-steps 100
```

按显式任务：

```bash
python -m geomind.runners.run_suite \
  --task-ids PlaceDirectionalSem_v0 SelectByDistance_v0
```

## 结果位置

- 单任务：`<output_dir>/result.json`
- 批量：`<output_dir>/<task_id>/result.json` + `<output_dir>/summary.json`

可用下面命令再次汇总：

```bash
python -m geomind.tools.summarize_results --suite-dir geomind/outputs/suite/<timestamp>
```
